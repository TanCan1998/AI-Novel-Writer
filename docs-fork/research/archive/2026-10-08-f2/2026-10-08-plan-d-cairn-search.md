## 依赖冲突问题

### 发现的冲突

```
error: package `libsqlite3-sys` links to native library `sqlite3`, but conflicts with:
  - libsqlite3-sys v0.38.2 (from rusqlite v0.40.2) ← 我们当前用的
  - libsqlite3-sys v0.30.1 (from rusqlite v0.32.0) ← cairn-search 需要的
```

**根因**：
- 当前项目用 `rusqlite = "0.40.2"`
- cairn-search 依赖 `rusqlite = "0.32"`
- **同一个二进制不能链接两个版本的 SQLite**

### 解决方案

#### 选项 1：降级 rusqlite（推荐）
```toml
[dependencies]
rusqlite = "0.32"  # 降级到与 cairn-search 兼容
cairn-search = "0.1"
```

**影响评估**：
- ⚠️ 需要检查 0.32 → 0.40 的 API 变化
- ⚠️ 可能需要小幅修改现有代码
- ✅ 一次性解决，后续无冲突

#### 选项 2：等待 cairn-search 升级
- ⏳ 联系作者升级到 rusqlite 0.40
- ⏳ 时间不可控

#### 选项 3：Fork cairn-search
- 🔧 Fork 并升级依赖
- ⚠️ 需要维护 fork
